# Interactive joinpoint graphics

Draws a joinpoint figure as an interactive graphic: an htmlwidget made
with the `ggiraph` package that looks like the static figure and adds
tooltips, linked highlighting and zoom. Hovering a fitted segment shows
its period and APC with confidence interval and p value, and highlights
the segment with its label and band while dimming the rest; hovering an
observation shows its value, confidence interval and fitted trend;
hovering a joinpoint shows its location and confidence interval. The
toolbar zooms and saves the graphic as a PNG image.

## Usage

``` r
jp_interactive(
  x,
  plot = c("trend", "apc", "aapc", "selection"),
  ...,
  width = 7.5,
  height = 5,
  zoom = 5,
  embed_fonts = FALSE
)
```

## Arguments

- x:

  A `joinpoint` object, or a ggplot made by one of the plot functions of
  the package with `interactive = TRUE` (and possibly modified, for
  example with further labels or theme settings).

- plot:

  The figure drawn from a `joinpoint` object: `"trend"`
  ([autoplot()](https://skhademioore.github.io/joinpoint/reference/autoplot.joinpoint.md)),
  `"apc"`
  ([`plot_apc()`](https://skhademioore.github.io/joinpoint/reference/plot_apc.md)),
  `"aapc"`
  ([`plot_aapc()`](https://skhademioore.github.io/joinpoint/reference/plot_apc.md))
  or `"selection"`
  ([`plot_selection()`](https://skhademioore.github.io/joinpoint/reference/plot_selection.md)).

- ...:

  Further arguments to the plot function, for example
  `color_by = "trend"` or `log_y = TRUE`.

- width, height:

  Size of the graphic in inches; the widget scales to the width of its
  container, keeping this aspect ratio.

- zoom:

  Maximum zoom factor (`1` for no zoom).

- embed_fonts:

  Embed the font files in the widget, so that it looks exactly the same
  on every computer. By default the text uses fonts found on the system
  (Arial, Helvetica or DejaVu Sans, for example), which keeps the widget
  small: about 0.2 MB instead of several MB.

## Value

An htmlwidget of class `girafe`.

## Details

The widget works in the RStudio viewer, R Markdown and Quarto HTML
documents, pkgdown sites and Shiny applications (with
[`ggiraph::girafeOutput()`](https://davidgohel.github.io/ggiraph/reference/girafeOutput.html)
and
[`ggiraph::renderGirafe()`](https://davidgohel.github.io/ggiraph/reference/renderGirafe.html)).
[`jp_save()`](https://skhademioore.github.io/joinpoint/reference/jp_save.md)
writes it to a standalone HTML file. Documents rendered to Word or PDF
need the static figures
([autoplot()](https://skhademioore.github.io/joinpoint/reference/autoplot.joinpoint.md)
and the other plot functions).
